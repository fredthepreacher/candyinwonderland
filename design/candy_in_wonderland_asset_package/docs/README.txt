Candy in Wonderland Asset Package

Purpose:
This package collects the extracted/generated PNG assets from the chat so they can be handed off to a coworker or Claude for integration into the game.

Folder guide:
- characters/main_character: Candy sprite references and character sheets
- characters/npcs: gameplay NPC full-body sprites
- characters/portraits: dialogue portraits and portrait variants
- bosses: boss PNGs / variants
- ui: single UI/menu assets that are already split out
- props: single props already split out
- backgrounds: full background/environment images
- menu/assets: extracted title/menu art assets
- menu/text: extracted title/menu text assets
- reference_sheets: grouped sheets and supporting references for any missing assets that still need cleaner separation

Notes:
- Some items from the original project were extracted as fully separate PNGs.
- Some others still exist as grouped sheets and are included under reference_sheets so your coworker can continue refining/splitting them if needed.
- File names were normalized where useful, but original grouped sheet names were preserved for traceability.
