# Supplied visual assets

`candy_in_wonderland_asset_package/` is the supplied source art package, preserved in its original organization. The accompanying proposal is in `docs/asset-integration-handoff.md`.

These are design inputs for a future integration pass. Adding them does not change runtime asset mappings or implement the proposal's gameplay changes. The currently integrated artwork remains in `artifacts/candy-in-wonderland/public/assets/`.

Reference sheets and unused source images remain outside the public directory so the production build does not copy them into the deployed game.
